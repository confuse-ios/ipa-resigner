# 小蟹iOS-重签名工具

一款基于 Qt 开发的 macOS 平台 IPA 重签名工具，支持证书管理、配置管理和动态库注入等功能。

## 功能特点

- **证书管理**：查看和管理 iOS 签名证书
- **配置管理**：保存和管理多个签名配置
- **动态库注入**：支持向 IPA 包注入自定义 dylib
- **多语言支持**：中文和英文界面（自动检测系统语言）

## 下载

请从 [Releases](https://github.com/confuse-ios/ipa-resigner/releases) 页面下载最新版本：

- `小蟹iOS-重签名工具.zip` - 压缩包

## 安装说明

1. 下载并解压 ZIP 文件
2. 双击 DMG 文件
3. 将应用拖放到 Applications 文件夹
4. 从 Launchpad 或 Applications 中启动

## 使用方法

### 1. 配置签名信息

1. 点击「签名配置」按钮
2. 点击「添加」创建新的签名配置
3. 选择证书和 provisioning profile
4. 点击「保存」

### 2. 选择 IPA 文件

1. 点击「选择IPA文件」
2. 选择要重签名的 IPA 文件
3. 应用会自动分析 IPA 信息

### 3. 开始重签名

1. 选择签名配置
2. 可选择启用动态库注入
3. 点击「开始重签名」
4. 等待重签名完成

## 系统要求

- macOS 10.15 或更高版本
- Xcode 命令行工具（用于代码签名）

## 常见问题

### 应用无法打开

如果出现 "无法验证开发者" 的提示：
1. 进入「系统设置 > 隐私与安全性」
2. 点击「仍要打开」
3. 再次尝试打开应用

### 证书选择失败

- 确保证书已安装在钥匙串中
- 确保证书未过期
- 检查证书权限

## 语言说明

应用会自动检测您的系统语言：
- 如果系统语言是中文，界面将显示中文
- 否则，界面将显示英文
